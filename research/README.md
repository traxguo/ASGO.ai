# Araştırma

| Klasör | Ne var |
|---|---|
| `data/` | Veri indirme yedeği (`fetch_binance_vision.py`) ve veri doğrulama (`validate.py`). Doğrulama raporu: `data/validation_report.md` (veri indirilince oluşur). |
| `robustness/` | Dayanıklılık testleri (walk-forward, ±%20 parametre, Monte Carlo) — Seviye 1. |
| `universe/` | Seviye 2 dinamik coin evreni hesapları. |
| `reports/` | Birden fazla testi kapsayan özet araştırma raporları. |

Veri doğrulama sorunları sadece raporlar, veriyi sessizce düzeltmez.
